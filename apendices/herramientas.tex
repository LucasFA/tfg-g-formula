\chapter{Herramientas}\label{ap:herramientas}
Agradezco la existencia de ciertas utilidades de software libre utilizadas a lo largo del trabajo:
\begin{itemize}
    \item R, la suite numérica \cite{rlang},
    \item \LaTeX, el software de composición tipográfica,
    \item Nix, un gestor de paquetes declarativo \cite{dolstra_Nix} \cite{dolstra2006nix}
    \item Zed, un editor de texto \cite{zedEditor},
    \item GNU Parallel, que permite paralelizar scripts \cite{gnuParallel}
    \item y numerosos paquetes de \LaTeX
\end{itemize}
